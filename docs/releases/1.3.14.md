# FindDiskKiller 1.3.14

This release corrects the app icon's visual size so it fits naturally beside
other applications throughout macOS.

## App icon

- Keep the existing disk and magnifier artwork while moving it into the macOS
  app icon safe area.
- Add balanced transparent margins so the icon no longer appears oversized in
  Launchpad, Spotlight, Finder, or the Dock.
- Add a deterministic generator for every required ICNS representation, from
  16 to 1024 pixels, to keep future icon exports consistent.

## Release integrity

- Build 136 passed the serial Swift test suite, lint checks, Xcode archive, and
  release validation workflow.
- The release is universal, Developer ID signed, notarized,
  Gatekeeper-validated, and Sparkle-signed before publication.
